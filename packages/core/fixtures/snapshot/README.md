# Snapshot fixtures

Inputs and outputs of the readers in `src/snapshot/`, served to the tests there.

- `snapshot.json` is a complete snapshot in its JSON form, the shape `decodeSnapshot` accepts and `encodeSnapshot` returns. The round-trip test pins that the two shapes are the same and that timestamps stay strings.
- `drift/<code>.json` is one `Collected` input per drift code in the catalogue (`warningCodes` in `src/snapshot/warnings.ts`): the smallest tracker state that makes `readSnapshot` raise that code. A code without a fixture fails the test suite. The local-tracker codes (`map-title-from-directory`, `map-file-ambiguous`, `map-status-unknown`, `header-key-bold`, `ticket-title-from-slug`, `unknown-status`) use a `.scratch` effort; the rest use GitHub facts. A local map's `mapFiles` lists the map files its effort holds when there are several.
- `maps/hero-synergy-1.json` is this repo's own map, [#1 hero-synergy v0.1.0, fully decided](https://github.com/dbarjs/hero-synergy/issues/1), with its 33 sub-issues, recorded from `gh api graphql` on 2026-10-07 and converted to the `Collected` shape: the tracker's facts and the raw bodies, bodies unread. The test reads it and asserts every field exact.
- `maps/legacy-forms.json` is the scout prototype's legacy fixture (`prototype/scout`, `packages/core/scout-prototype/fixtures/legacy.mjs`), converted the same way: a Notes / Decisions so far / Fog map with a task list of children, `Part of #n` and `Blocked by:` lines, a `wayfinder:claimed` label, a `Type:` line, tickets without `## Question`, a ticket with two type labels, closed tickets the map never recorded, and a free-form map written by hand. The test asserts the warnings the prototype reported, one per drift point.

A `Collected` holds what a tracker reports before any body is read: on GitHub the issue's title, state, labels, assignees, native parent, native blockers (closed ones included) and last comment; on a local tracker `title`, `state` and `lastComment` are null, since the body's H1, `Status:` line and `## Answer` section hold them.
