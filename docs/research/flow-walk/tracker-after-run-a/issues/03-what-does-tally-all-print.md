# 03: What does `tally all` print?

Type: grilling
Status: resolved

## Question

What does `tally all <file>` print, and how do the single-count subcommands relate to it?

## Answer

One report of three counts, in the order words, lines, characters, through the existing report formatter. The subcommands `words`, `lines` and `characters` each print a one-count report named after the subcommand. Words follow the glossary.
